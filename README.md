# Flujo para la instalación del proyecto

### 1. Clonación del proyecto
    git clone https://github.com/R0bert0Vazquez/RAFH-MOBILE.git
    cd RAFH-MOBILE

### 2. Instalación de dependencias
    npm install

### 3. Ejecutar el proyecto
    npx expo start

# Notas:
  Si hay errores de dependencia
  ### Limpiar cache e reinstalar
    npm cache clean --force
    rm -rf node_modules
    npm install
